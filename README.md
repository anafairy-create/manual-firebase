# Manual Firebase — React Native

Projeto desenvolvido para a atividade de documentação do Firebase Authentication em um aplicativo React Native.

## Funcionalidades

- Cadastro com e-mail e senha
- Login
- Logout
- Mensagens para situações de erro
- Navegação entre as telas

## Tecnologias

- React Native
- Expo
- Firebase Authentication
- React Navigation
- JavaScript

## Como executar

```bash
npm install
npx expo start
```

Para Android:

```bash
npx expo start --android
```

## Configuração do Firebase

O projeto utiliza Firebase Authentication com e-mail e senha. Antes de executar, confira se o projeto do Firebase está configurado e se o método de autenticação por e-mail e senha está ativado.

## Observação

Este projeto foi adaptado a partir de um projeto local existente para a atividade de criação do manual sobre Firebase Authentication.
